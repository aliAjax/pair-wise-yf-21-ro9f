# hxyfront-62009 地毯修复纹样档案 · 对称推花

源提示词编号：2

给手工地毯修复工作室使用的纹样与修复档案前端。核心场景是**边缘花边续纹的对称推花**：

- 在完整侧选定 **3 个锚点**，再在破损侧点出 **3 个对应落格**，系统按对称（仿射）关系推算出其余全部落点并标记在格网上。
- **三组对不上**（三组锚点/落格格距不一致、锚点共线、落点偏离格位或出界）、**目标格重合**、**缺参照**（锚点或落格不足三个）时，该区域转入 **待复核**，补线入口不开放。
- 待复核区域须由 **负责人确认替代方案并填写原因** 后，补线入口才开放。
- **改锚点或格位** 会使既有推算与负责人确认一并失效（留痕），需重新推算/复核；**已完成区域照旧保留**、锁定不可改。
- 推算、复核、失效、完工全程留痕于「复核前后记录」，档案存于 localStorage，**关闭页面后再打开仍可查看**。

另包含：纹样局部标记图、修复前后记录、材料色卡、工序进度、按产地筛选的档案列表。

## 分层结构（推算 / 存档 / 页面操作分三处维护）

```
src/core/projection.ts    推算层：纯函数，解对称仿射、校验三组格距/重合/缺参照
src/core/archiveStore.ts  存档层：档案状态与 localStorage 持久化
src/core/archiveOps.ts    页面操作层：选点、推算、复核确认、完工等状态变更
src/core/types.ts         领域类型与状态推导（deriveStatus / isEntryOpen）
src/core/seed.ts          示例档案（选点中 / 待复核 / 已确认方案 三种状态）
src/components/           页面组件（格网标记图、区域面板、档案侧栏）
```
