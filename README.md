# hxyfront-62009 地毯修复纹样档案

源提示词编号：2

做一个给手工地毯修复工作室使用的纹样与修复档案前端项目，可以记录地毯产地、年代、结密度、材质、染色类型、破损区域、补线颜色和修复工序。页面需要有纹样局部标记图、修复前后记录、材料色卡、工序进度和按产地筛选的档案列表。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62009

## 边缘花边对称推花

档案台内置「对称推花」工作台，用于替代目测续纹：

- 完整侧选 3 个锚点，点出破损侧落格（锚点①的落格必填，②③ 可点作复核），系统按对称轴推算其余落点
- **三组对不上**（反推对称轴与档案轴不符 / 落点越界或不在破损侧 / 所点落格与推算不一致）、**目标格重合**（落点撞上旧针脚占用格或彼此重合）、**缺参照**（锚点不足 3 个或未落格）时，该区转**待复核**，补线入口不开放
- 负责人填写**替代方案、原因、确认人**后才能施工；改锚点或落格格位会使确认失效，需重新复核
- 已完成区域照旧保留并锁定，不受其他区改动影响
- 复核前后快照与全过程记录持久化，关闭页面再打开仍可回看

### 代码结构（推算 / 存档 / 页面操作分三处维护）

- `src/lib/inference.ts` —— 推算：对称几何、落点推算与三类校验的纯函数
- `src/lib/archive.ts` —— 存档：推花区状态、复核快照与流水记录的持久化
- `src/components/SymmetryStudio.tsx` —— 页面操作：格图选点、状态流转、负责人复核表单与记录展示
